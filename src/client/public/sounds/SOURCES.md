# Sound sources

Every world sound is a CC0 file by Kenney (www.kenney.nl), renamed after the sound it plays. kenney.nl refuses automated downloads, so the packs were taken from Kenney's own uploads on OpenGameArt. Each pack's licence is in `licences/`. `opengameart.org/content/rpg-audio` is a different author's pack; Kenney's RPG Audio is the `50-rpg-sound-effects` page.

| Pack             | Downloaded from                                                                                                   | Licence                         |
| ---------------- | ----------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| RPG Audio        | https://opengameart.org/content/50-rpg-sound-effects (`RPGsounds_Kenney.zip`, unversioned)                        | `licences/rpg-audio.txt`        |
| Casino Audio     | https://opengameart.org/content/54-casino-sound-effects-cards-dice-chips (`kenney_casino-audio.zip`, version 1.1) | `licences/casino-audio.txt`     |
| Interface Sounds | https://opengameart.org/content/interface-sounds (`kenney_interfaceSounds.zip`, version 1.0, created 2020-11-02)  | `licences/interface-sounds.txt` |
| Music Jingles    | https://opengameart.org/content/85-short-music-jingles (`jingleSounds_Kenney.zip`, unversioned)                   | `licences/music-jingles.txt`    |

Kenney's Impact Sounds isn't mirrored anywhere reachable, so footsteps and Clash sounds come from RPG Audio instead. The three footsteps are different takes, picked from softest (Forest) to brightest (Dungeon).
